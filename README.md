# 🍕 Zomato SQL Analysis Project

## 📌 Project Overview
This project performs end-to-end SQL analysis on a 
Zomato-style restaurant dataset using MySQL.

## 🗃️ Database Schema
The project uses 5 tables:
- **converted_table** — Restaurant information
- **dataset_table** — Order transactions
- **food_items** — Food item details
- **menu** — Restaurant menu with prices
- **users** — Customer demographics
